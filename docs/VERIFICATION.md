# Проверки на версия 1.1.0

Изпълнени на 10.09.2026: локално macOS arm64/Python 3.12 и GitHub Actions
Ubuntu/Python 3.12 с Docker Compose.

## Проверено

- 43 автоматични теста: валидиране, точни полета, ред на нарежданията,
  кирилица, водещи нули, липсващи контакти, брой позиции, грешни заявки,
  едновременни заявки без смесване на данни, CLI и HTTP отговори.
- Групиране по ID/точно име, стари заявки без ID, повторни посещения, различни
  фирмени телефони, запазен ред, непроменен вход и една статична отметка на група.
- Продължена клиентска шапка без повторна отметка; групата започва на първата
  страница, когато има място за нареждане. Шест отделни клиента запазват данните.
- QR декодиране от растеризиран PDF: точното UTF-8 course ID на всяка страница.
- Един и шест нормални записа; дванадесет и двадесет записа с пренасяне;
  100 записа се приемат, 101 се отхвърлят с валидационна грешка.
- Много дълга бележка и адрес: текстът е запазен, с обозначено продължение.
- Визуален преглед на примерите с 6 и 12 нареждания и стресови страници
  с дълги имена/адреси; без отрязване или застъпване.
- OpenAPI използва същата схема като runtime валидирането.
- Построени wheel и source distribution с включени шрифтове и лиценз.
- Wheel инсталиран в чиста отделна среда само с декларираните runtime зависимости.
- CLI и действителна HTTP заявка към Waitress от инсталирания wheel: получен
  едностраничен PDF. Временната услуга е спряна след проверката.
